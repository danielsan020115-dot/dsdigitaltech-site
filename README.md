# DS Digital Tech — Site institucional

Site estático responsivo da DS Digital Tech, preparado para GitHub Pages.

## Teste local
Abra `index.html` no navegador ou utilize a extensão Live Server no VS Code.

## Estrutura
- `index.html` — Home e produtos
- `privacidade.html` — Política de Privacidade
- `termos.html` — Termos de Uso
- `assets/css/style.css` — identidade visual e responsividade
- `js/i18n.js` — PT/EN/ES da Home
- `js/app.js` — menu mobile
